- Moderne : délègue à `neoforge::parse_installer` / `run_processors` / `write_version_json` (types `InstallerProfile`, `ProcessRunner`, `ProcessContext` réexportés). Ancienne : jar universel copié dans `libraries/`, pas de processeurs.

- `install(inst, ctx, versions_dir, runner)` : libraries/universel, version.json atomique, processeurs ; `merge_with_vanilla` (minecraftArguments du profil prioritaire en ancienne ère).
- Sécurité : zip-slip (`enclosed_name`), tailles bornées (JSON 16 Mo, entrée 256 Mo, installeur 512 Mo), id/version sans `..`.

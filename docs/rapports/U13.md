Fichiers : state.rs (AppState, Paths, EventSink), p2p_backend.rs (trait P2pBackend + UnavailableBackend), error.rs (messages sans chemin/jeton), install.rs (vanilla, libraries, natives, assets, loaders, Java), commands_{auth,instances,friends,join,settings}.rs, lib.rs, capabilities/default.json (minimize/close/start-dragging). `decorations:false` était déjà là.
Branchées : auth_status/begin/poll/logout (Device code + Xbox + Minecraft + TokenStore), auth_offline_login (CUBELINK_TEST_MODE=1), instances_list/create (vanilla, fabric, quilt, neoforge, forge)/import_mrpack/launch (launch://state)/minecraft_versions, settings_get/set (settings.json), friend_my_code/regenerate_code/list/requests/accept/refuse/refuse_all (identity, friend_code, friends_db), join_plan/start/pause/resume/cancel (plan N10 réel).
Provisoires (UnavailableBackend, TODO(P2P)) : friend_send_request (valide le code puis « pas encore disponible »), présence (toujours hors ligne), manifeste de l'ami et réception des fichiers (join_plan/join_start renvoient l'erreur), friend://presence et friend://request jamais émis, unknown_mods du plan vide, instance invitée (core::guest vide).
Notes : settings_set/instances_create/friend_requests reçoivent les champs à plat (comme src/services/tauri.ts). mrpack::import tourne via spawn_blocking+block_on (son futur n'est pas prouvé Send).
Limites : pas de refresh du jeton Microsoft (auth_status ne renvoie le profil que si le jeton Minecraft est valide) ; identifiant Azure via CUBELINK_MS_CLIENT_ID (exécution ou compilation) ; Java sous Linux/macOS non installable (tar.gz, J2) ; installation de loader non testée en réel (pas de réseau en test).
Tests : 18 unitaires verts (offline refusé sans drapeau, settings aller-retour, création invalide, code ami invalide, etc.) ; clippy -D warnings propre. Dépendances ajoutées par le team lead : reqwest, tempfile (dev).

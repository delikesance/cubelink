# E0.2 : faux miroir Mojang + faux java (tests-fixtures/mojang)
Fichiers : server.mjs, zip.mjs, fake-java.{mjs,cmd,sh}, mirror.test.mjs, fake-java.test.mjs, README.md. Tests : `node --test "tests-fixtures/mojang/*.test.mjs"` : 14 verts, 1 ignoré (SIGTERM, Windows). Note : Node 24 refuse `node --test tests-fixtures/mojang/` (dossier nu), d'où le glob.
Miroir : manifeste v2 (2 versions), version.json (arguments + règles, 2 libraries dont natives win/linux/mac, assetIndex, client.jar zip valide), 3 assets, Fabric meta (liste, profil, Maven), Adoptium + JRE zip (bin/java.exe et bin/java). sha1/sha256/tailles dynamiques. `/__control` (bad_hash, 404, 500, slow, times, reset) et `/__state`.
Faux java : -version, témoin JSON (jeton masqué), vérif classpath (code 1 si manquant), faux monde LAN (handshake 0x42 -> 0x24, écho), "Done", arrêt par SIGTERM ou fichier, code de sortie par env.
MANQUES POUR LE TEAM LEAD (aucune surcharge d'URL dans l'app) :
- `fetch_manifest()` (versions.rs), `download_assets(.., None, ..)` (install.rs:327), `java_install::resolve_package` (install.rs:136) et Fabric (`FabricClient::new`) utilisent les constantes par défaut : il faut une variable d'env de test (ex. CUBELINK_TEST_MANIFEST_URL, _RESOURCES_URL, _ADOPTIUM_URL, _FABRIC_META_URL), idéalement derrière CUBELINK_TEST_MODE=1. Les URLs libraries/client/index sont absolues dans le version.json, donc rien à ajouter.
- Chemin de java : le réglage `java_path` existe (settings), mais commands_settings.rs le valide (le test met notepad.exe) : vérifier qu'il accepte `fake-java.cmd`.
- Limite : sous Windows `bin/java.exe` du faux JRE est un texte, non exécutable ; la sonde `-version` après installation échouera. Pour T3 utiliser `java_path` vers fake-java.cmd, ou prévoir une sonde de test.

# U10 : onglet « Ajouter un ami »
- Fichiers : `src/screens/Friends/Add.tsx`, `add.css`, `Add.test.tsx` (export par défaut `Add`, export nommé `validateFriendCode`).
- Validation : regex `^(mcl1-[A-Za-z0-9-]{16,}|launcher://add/\S+)$` en insensible à la casse, après trim ; erreur affichée après saisie/blur et à l'envoi, liée au champ (aria-describedby, aria-invalid) ; aucun appel au service si invalide.
- Bouton « Envoyer la demande » désactivé tant que vide ou pendant l'envoi ; envoi via `friendSendRequest(code)`.
- Succès : « Demande envoyée. Compare ce code avec celui de ton ami » + code de vérification en grand ; champ vidé ; zone aria-live pour envoi/succès.
- Erreur du service : message du service (fr) en `role="alert"`, champ conservé.
- Bouton « Coller » (presse-papiers, repli silencieux avec focus sur le champ). Focus #FF8A4A, boutons ≥ 44 px.
- Limite : les messages « déjà ami / hors ligne » dépendent du texte d'erreur renvoyé par le service (pas de codes d'erreur typés).
- Tests : 7 (valide, invalide, lien launcher://, erreur service, vide, coller, règles).

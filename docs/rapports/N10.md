# N10 : plan de transfert (p2p/src/transfer/plan.rs)

- `compute_plan(manifest, &dyn CacheLookup) -> Result<Plan>` et `compute_plan_with(.., &PlanOptions)` (`max_total_bytes` = 20 Go par défaut, `largest_first`).
- Garde-fous : `validate_manifest` d'abord ; plafond dépassé -> `Error::Invalid` en français ; même sha256 avec tailles différentes -> rejeté ; manifeste vide -> plan vide.
- En cache seulement si hash ET taille concordent (`CacheLookup::has`) ; adaptateur `StoreCache(&StoreIndex)` (erreur d'index = absent).
- Dédup : `to_receive` unique par sha256 ; `installs` garde tous les (chemin, sha256), triés par chemin ; tri déterministe indépendant de l'ordre d'entrée.
- `to_join_summary(&Plan) -> (cached, to_receive, to_receive_bytes)`.
- `total_bytes` = somme des tailles de tous les chemins du manifeste (plafond appliqué dessus).
- Tests : 90/3, doublons, taille divergente, hostile, plafond, vide, déterminisme + largest_first.

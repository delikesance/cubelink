# M4 : index et téléchargement des assets

- Fichier : `core/src/mojang/assets.rs` (11 tests wiremock verts).
- `fetch_asset_index(&AssetIndexRef, assets_dir)` : sha1 vérifié, écrit `indexes/<id>.json` (atomique). Le paramètre `assets_dir` est ajouté à la signature demandée.
- `download_assets(index, dir, base_url: Option<&str>, progress, concurrency)` + `download_assets_with(.., &DownloadOptions)` (concurrence, tentatives=3, délai injectable, `cancel: Arc<AtomicBool>`).
- Objets dédoublonnés par hash, hash validé (40 hex) contre les chemins piégés ; présent+valide = sauté ; corrompu supprimé puis retéléchargé ; `.part` résiduel écrasé ; rename atomique.
- Retry sur erreur réseau/5xx ; 404 = `NotFound` sans retry ; sha1/taille faux = `Integrity` sans retry, rien laissé sur disque ; annulation = `Cancelled`.
- `sha1_hex` de versions.rs est publique et réutilisée. Limite : l'objet est lu en mémoire (assets petits).
- Progression : `AssetProgress{files_done, files_total, bytes_done, bytes_total}` après chaque objet.

## Ecartes

- Background Nightsky (tigitalart, CC0) : style cartoon doux, clair, pas voxel.
- Packs de portraits "25 Portrait Pixel Art pack1" (CC0) : visages reels pixelises, risque de droit a l'image, ecarte.
- "RPG Characters Avatars" (CC0) : rendus 3D realistes, hors style.
- "Sandbox Style - Terrain Pack" demo (CC0) : textures tres proches de Minecraft (minerais), risque de confusion avec les assets Mojang, ecarte.
- Loopable mountain backgrounds (Vircon32, CC-BY 4.0) : style jour pastel hors charte sombre.
- Space Background (code32), Seamless cave background (PWL) : photo de nebuleuse / aplats gris-verts, hors style.
- Packs Kenney (Blocky Characters, Voxel Pack, Isometric Blocks, CC0) : la page est reperee mais le telechargement kenney.nl est bloque pour les scripts (403) et les apercus portent un logo ; non retenus.

## Limites

- Aucune vraie image voxel/low-poly sous licence libre en grand format n'a ete trouvee : le style retenu est le pixel-art nocturne (coherent avec la charte sombre) ; un rendu voxel original reste a commander ou a produire (ex. Kenney Blocky Characters / Isometric Blocks rendus soi-meme, CC0).
- hero-2 et hero-4 sont des agrandissements x4/x5 de tres petites sources : rendu volontairement "gros pixels", prevoir `image-rendering: pixelated`.
- Les couleurs de hero-3 (teal) et hero-1 (bleu) devront probablement etre assombries par un overlay #0A0A0A pour garder le contraste du titre blanc.

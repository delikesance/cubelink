# Rapport M3 : extraction des natives

- Fichier : `core/src/mojang/natives.rs` ; `extract_natives(libs, libs_dir, natives_dir) -> Result<ExtractReport>` (extracted, unchanged, skipped, bytes).
- Ne traite que les `is_native` ; jar absent -> `Error::NotFound` (nom de la lib) ; zip illisible -> `Error::Invalid`.
- Zip-slip : chaque entrée est validée avant tout (`..`, `/` ou `\` initial, `:` de lecteur, octet nul, lien symbolique unix) -> `Error::Invalid`, rien d'écrit pour l'entrée ni hors de `natives_dir`.
- Exclusions par préfixe (`META-INF/`), dossiers ignorés.
- Bornes : 128 Mo par entrée, 256 Mo au total (lecture plafonnée via `take`, donc robuste aux en-têtes mensongers).
- Écriture atomique (`.tmp` + rename) ; idempotent (contenu identique -> `unchanged`, pas de réécriture).
- Tests (7) : nominal, excludes, non-natif, zip-slip, absolu/lecteur/backslash, jar manquant, idempotence + réparation, limites de taille. Clippy `-D warnings` OK.
- Limite : un `..` dans une entrée même exclue fait échouer l'archive (choix strict).

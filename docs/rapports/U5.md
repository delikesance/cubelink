# U5 : écran Créer une instance

- Fichiers : `src/screens/Create/{index.tsx,create.css,index.test.tsx}`.
- Dialogue modal (role=dialog, aria-modal, aria-labelledby), focus initial sur Nom, piège Tab/Maj+Tab, focus restauré au démontage, Échap = Annuler.
- Versions via `minecraftVersions()` (1.21.1 présélectionnée et marquée recommandée), loaders en radios, RAM dans « Options avancées » (défaut 4 Go).
- Nom validé (non vide, ≤ 64, pas de `< > : " / \ | ? *`), erreur liée par aria-describedby/aria-invalid.
- Créer : `instancesCreate({name, minecraft, loader:{loader, version:""}, ram_mb})` puis `#/main`; erreurs du service en français (role=alert), bouton désactivé pendant l'appel.
- Import : prop `pickMrpack?: () => Promise<string|null>` injectable (sélecteur natif futur) ; par défaut champ texte du chemin + `instancesImportMrpack`.
- Tests : création, nom invalide, Échap, Annuler, erreur service, import.
- Limites : le Shell doit rendre `<Create />` sans props ; le routeur n'a pas de superposition sur Main (écran plein, pas de fond Main visible).

# N17 - Relais : configuration, observation, avertissement (p2p/src/relay.rs)

- API : `RelaySettings{mode: RelayChoice::{Default,Custom(String),Disabled}, relay_only, allow_relay}`, `plan()` (mapping pur), `build_endpoint(SecretKey, &RelaySettings, alpns)`, `validate_relay_url`, `relay_hint`/`relay_hint_from_code`, `PathKind`, `kind_of`, `PathObserver` (`current`, `changed`, `subscribe`), `SlowRelayAdvisor`/`Advice`/`AdvisorConfig`.
- Modes : allow_relay=false ou Disabled => `RelayMode::Disabled` ; relay_only => `clear_ip_transports()` ; relay_only + relais désactivé => erreur « contradiction » ; Custom => https obligatoire, http seulement loopback, sans identifiants.
- Advisor (pur, temps injecté) : relais + débit < 2 Mo/s (fenêtre 3 s) pendant > 5 s => `SlowViaRelay{speed_bps}` ; levé à >= 2,5 Mo/s pendant 3 s ou chemin non relais ; transfert à l'arrêt = inactif (pas d'alerte). Événements seulement aux transitions. Message FR sans prétendre que le relais ne voit rien.
- Code ami : `relay` du payload (`host[:port]` ou URL) => `RelayUrl` validé ; invalide => `None` (indice non fiable, s'y connecter expose l'IP à un tiers).
- Écart : `Identity` n'expose pas sa clé secrète, donc `build_endpoint` prend un `iroh::SecretKey`. Il faut un accesseur `Identity::secret_bytes()` à l'intégration (hors périmètre).
- Écart : la feature iroh `test-utils` n'est pas activée dans `p2p/Cargo.toml` : pas de relais local. Le test relais seul `relay_only_uses_relay_path` est `#[ignore]` (relais publics n0, Internet requis).
- Tests : 11 OK + 1 ignoré (advisor, mapping, URL, code ami, direct seul loopback => `PathKind::Direct`, contradiction/URL http refusées). Clippy `-D warnings` propre.

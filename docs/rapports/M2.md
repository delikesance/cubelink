# Rapport M2 : libraries Mojang

- Fichier : `core/src/mojang/libraries.rs`.
- API : `Os`, `Arch` (+ `current()`), `Library`, `maven_path`, `resolve(&[Value], Os, Arch)`, `classpath(&[Library], &Path)`.
- Règles : sans règle = autorisée ; la dernière règle applicable l'emporte ; défaut refusé. `os.name` et `os.arch` évalués, `os.version` ignoré, `features` présentes = règle non applicable.
- Natives anciennes : `natives` + `downloads.classifiers`, `${arch}` -> 32/64, `extract.exclude` ; sans `downloads`, chemin Maven + classifier.
- Format ancien (`name` seul) : chemin Maven, base `url` de l'entrée ou `https://libraries.minecraft.net/`.
- Natives exclues du classpath. JSON mal formé (non objet, `name` absent ou non Maven, `rules` invalide) -> `Error::Invalid`.
- Tests : règles par OS, arch/features/version, natives 1.12, LWJGL moderne, format ancien, classpath, erreurs.

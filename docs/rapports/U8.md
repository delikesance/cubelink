# U8 : bloc « Mon code ami »

- Fichiers : `src/screens/Friends/MyCode.tsx` (export par défaut), `mycode.css`, `MyCode.test.tsx`.
- Bandeau `position:sticky; top:0` (toujours visible au-dessus des onglets) ; fidèle à Friends.dc.html.
- `friendMyCode()` au montage ; états chargement (role=status) et erreur (role=alert + Réessayer).
- « Copier » : `navigator.clipboard.writeText`, message « Copié » (aria-live polite, effacé après 2 s) ; repli : code sélectionné + message.
- « Générer un nouveau code » : confirmation en ligne (ancien code invalide), Annuler possible, puis `friendRegenerateCode()` ; erreur affichée dans la confirmation.
- Accessibilité : focus #FF8A4A, boutons 44 px, `<code>` avec aria-label contenant le code.
- Tests : 5 (affichage, copie + disparition, repli, régénération annulée/confirmée, erreur + Réessayer). lint, test:front (42/42) et build OK.
- Note : le parent doit être un conteneur flex/scroll pour que le sticky joue son rôle ; index.tsx rend un simple `<div>`, sticky reste correct tant que le défilement est dans un ancêtre.

# Rapport A5 : auth/offline.rs

- API : `offline_uuid`, `offline_profile`, `test_mode_enabled`, `offline_login`.
- UUID : MD5 de `OfflinePlayer:<pseudo>`, version 3 + variante RFC 4122 (= `nameUUIDFromBytes`).
- Vérifié par calcul (Python) : Notch = b50ad385-829d-3141-a216-7e7d7539ba7f (conforme).
- Pseudo : 3 à 16 caractères `[A-Za-z0-9_]`, sinon `Error::Invalid` (message français).
- Mode test : lecture injectable (`mode_from`, `login_with`) donc tests sans variables d'environnement globales.
- `offline_login` hors mode test : `Error::Auth`.

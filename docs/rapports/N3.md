# N3 - friend_code.rs
- Implémenté `p2p/src/friend_code.rs` : `FriendCodePayload`, `encode`, `parse`, `to_link`.
- Binaire : version(1) | epoch u32 BE | clé(32) | relais (len u8) | nb adresses u8 | adresses | CRC-32 ; base32 minuscule, groupes de 4, préfixe `mcl1-`.
- Le code peut contenir relais et adresses d'indice (aucun secret, mais pas "sans adresse").
- Bornes : chaînes <= 64 octets, <= 8 adresses (`encode` ignore ce qui dépasse), code normalisé <= 1024 caractères.
- CRC-32 maison (pas de crc32fast) ; erreurs en `Error::Invalid`. Import : `core_lib::types` (nom de lib de core).
- Tests : 5 unitaires + 4 proptest (aller-retour, caractère modifié rejeté, pas de panic). Clippy -D warnings OK.

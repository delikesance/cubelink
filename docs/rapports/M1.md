# Rapport M1 : mojang/versions.rs
Fait : `VersionsClient` (URL du manifeste injectable, défaut piston-meta v2), fonctions libres `fetch_manifest()` / `fetch_version_json(&entry)`, `release_ids()` (releases, tri par `releaseTime` décroissant), `VersionManifest::find(id)`.
`VersionJson` : id, mainClass, assetIndex, downloads.client, libraries (JSON brut `Vec<Value>` pour M2), arguments (Value brut) / minecraftArguments, javaVersion.majorVersion (optionnel).
Erreurs : Network (réseau, HTTP != 2xx, manifeste 404 ou invalide), Integrity (sha1 faux, insensible à la casse), NotFound (version inconnue via `find`, 404 sur le JSON de version).
SHA-1 : implémentation minimale maison (`sha1_hex`, crate sha1 absente), testée avec les vecteurs RFC 3174 (vide, "abc", 56 octets, 1 million de "a"). Besoin éventuel : ajouter la crate `sha1` plus tard.
Tests wiremock : manifeste, tri, version trouvée, sha1 rejeté, inconnue, 404, format ancien.

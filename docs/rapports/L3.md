# Rapport L3 : loader Quilt

- Fichier : `core/src/loader/quilt.rs` (seul fichier de code touché).
- API : `QuiltClient::{new, with_meta_url, list_loader_versions, fetch_profile, install}`, fonctions libres équivalentes, `latest_stable`, `merge_with_vanilla`.
- Types `LoaderVersion`, `MergedVersion`, `InstalledProfile` réexportés depuis `fabric.rs` ; `merge_with_vanilla` délègue à Fabric.
- Meta : `/v3/versions/loader/<mc>` et `/<loader>/profile/json`. L'API Quilt n'a pas de champ `stable` : une version avec suffixe `-` (beta/rc) est instable.
- Maven par défaut des libraries sans `url` : `https://maven.quiltmc.org/repository/release/`.
- Sécurité/erreurs identiques à Fabric : 404 NotFound, réseau Network, sha1 Integrity, id/chemin `..` Invalid, écriture atomique, libraries valides sautées.
- Tests wiremock : liste, profil, installation 3 libs sur 2 Mavens (1 présente), 404/500, sha1, id dangereux, fusion.

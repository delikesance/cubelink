- API : `InstanceStore::new/create/create_with_kind/list/list_with_issues/get/delete/update_ram/game_dir/mod_count/kind/created_at`.

- `delete` : id strict `[A-Za-z0-9_-]`, refuse symlink, vérifie le parent canonique = racine. RAM 512-65536.

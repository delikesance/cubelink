# J2 - Installation de JRE (core/src/java_install.rs)
- API : `resolve_package(_from)(major, os, arch) -> JrePackage`, `install` / `install_with(…, Arc<dyn JavaProbe>)` -> `InstalledJava`. Versions 8/17/21/25 (21 = `DEFAULT_MAJOR`), sinon `Error::Invalid`.
- `JrePackage` a un champ en plus (`major`) pour savoir où installer. `ProcessProbe` = vrai `java -version` avec timeout 20 s.
- Flux : téléchargement en flux vers fichier temporaire, sha256 + taille vérifiés (`Error::Integrity`), extraction dans un dossier de staging, rename atomique vers `<java_root>/jre-<major>`, sonde finale (échec : installation retirée).
- Sécurité zip : `enclosed_name` (zip-slip, chemins absolus), liens symboliques refusés, bornes (50 000 entrées, 1 Go/fichier, 2 Go total, 512 Mo de téléchargement) sur les octets réellement écrits.
- Idempotent (installation valide = aucune requête) ; annulation -> `Error::Cancelled` + nettoyage ; 404 -> `NotFound`.
- LIMITE : pas de dépendance tar/gzip dans Cargo.toml, donc `.tar.gz` (Linux/macOS) renvoie `Error::Invalid` clair. À traiter si on ajoute `tar` + `flate2`.
- Tests : 10 tests wiremock (nominal, sha faux, déjà installé, zip-slip, annulation x2, 404, version/tar.gz, sonde négative, resolve). Clippy -D warnings propre.

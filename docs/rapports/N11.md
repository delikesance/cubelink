# N11 : transfert P2P (send.rs + recv.rs)

- `send.rs` : `trait BlobTransport { serve(Arc<Host>), fetch(peer, &FetchRequest, on_bytes, cancel), via_relay }` (async natif, génériques, sans nouvelle dépendance ; `async-trait` n'est pas une dépendance de p2p).
- Implémentations : `MemTransport`/`MemNetwork` (tests) et `IrohTransport` (iroh 1.4.1 + iroh-blobs 0.104.1, BLAKE3 côté réseau uniquement). iroh-blobs n'apparaît que dans `IrohTransport` : remplaçable.
- Iroh : ALPN de contrôle `cubelink/xfer/0` (sha256 -> BLAKE3, après `Host::authorize`), puis fetch iroh-blobs ; l'ALPN blobs est protégé par `GatedBlobs` (pair autorisé requis). Le store de l'hôte ne contient que les fichiers du manifeste importés à la demande (copie : `ImportMode::Copy`).
- Hôte : `ServeIndex::from_manifest` (manifeste validé, sha256 -> fichier du game_dir, jamais de chemin du pair), `PeerAuthorizer` (`AllowList` fourni ; `FriendsDb` implémentera le trait), `ServeLimits` (fichier, total par pair, requêtes simultanées par pair).
- Invité : `receive_plan(plan, peer, transport, store_root, &StoreIndex, &RecvOptions, progress, cancel)` : temporaire `store_root/.tmp`, taille + sha256 vérifiés (sinon `Error::Integrity`, fichier supprimé, rien dans l'index), rename atomique vers `object_rel_path`, `insert`. Concurrence bornée (`buffer_unordered`), progression `TransferProgress` (Preparing/Receiving/Verifying/Done/Failed/Paused, vitesse, via_relay), annulation `AtomicBool`.
- Point d'extension N13 : `FetchRequest.resume_from` (ignoré, 0) et `RecvOptions.skip_sha256`.
- Tests : 18 verts (nominal 5 fichiers, altéré, taille fausse, non autorisé, hors manifeste, annulation, limites, limites hôte) + `iroh_local_transfer` (`#[ignore]`, passe en 0,4 s avec `--ignored`).
- Limites connues : `via_relay` Iroh mesuré à la connexion ; reprise non implémentée ; `RecvOptions` et `peer` ajoutés à la signature demandée ; la progression Iroh est approximative par fichier. mod.rs déclare bien `send`/`recv`.

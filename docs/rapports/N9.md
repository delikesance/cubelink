# N9 : manifeste hôte (core/src/manifest.rs)

- `build_manifest(&Instance, &Path, &ManifestOptions) -> Result<Manifest>` ; `build_manifest_with(.., on_progress)` renvoie aussi `ManifestReport{skipped}` et appelle `ManifestProgress` par bloc de 1 Mo.
- Périmètre : `mods/**` (.jar seulement) ; `config`, `resourcepacks`, `shaderpacks` selon options. Tout le reste n'est jamais parcouru.
- Ignorés (avec raison) : fichiers cachés/système, noms évoquant jeton/identifiant, non UTF-8, liens symboliques hors dossier, vers dossier ou cassés.
- Sortie triée (octets) donc déterministe ; hash SHA-256 en flux ; `java_major` via `required_java_major` (+ `declared_java_major` optionnel).
- `manifest_hash` : JSON canonique (clés triées, sans espaces) ; vecteur fixe vérifié avec `sha256sum`.
- `validate_manifest` : `..`, absolu, `\`, lecteur, doublons (insensible à la casse), noms réservés Windows, caractères interdits, préfixes autorisés, sha256 minuscule 64, tailles, <= 10 000 fichiers.
- Tests : 6 (instance factice, déterminisme, exclusions, symlink sortant [saute si création impossible], manifestes hostiles, vecteur). Clippy `-D warnings` OK.

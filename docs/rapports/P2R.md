# P2R : un seul Router pour tous les protocoles (p2p)
Fichiers : `transfer/send.rs`, `tunnel.rs`, `transfer/resume.rs`, `relay.rs`, nouveau `manifest_channel.rs` (ligne `pub mod manifest_channel;` ajoutée dans `lib.rs`), test `p2p/tests/router_all.rs`.
1. `IrohTransport::handlers(host) -> (ControlHandler, GatedBlobsHandler)` + `handlers_dynamic(HostProvider)` (`Arc<dyn Fn() -> Option<Arc<Host>>>`, `None` = rien de partagé : changement d'instance sans recréer le Router). `serve` s'appuie dessus. Types exportés : `ControlHandler`, `GatedBlobsHandler`, `HostProvider`.
2. Tunnel : `HostTunnel::attach(authorizer, cfg)` (sans `endpoint.accept()`), `handler() -> TunnelHandler`, `set_world_port(&self, u16)` (0 = refus « rien partagé »). `start`/`start_with_config`/`stop`/`stats` inchangés ; `stop`/`drop` ferment aussi les connexions servies par un Router.
3. Manifeste : `ManifestServer::new(Arc<dyn PeerAuthorizer>)`, `set(Option<&Manifest>)` (validé, <= 4 Mio, l'ancien reste si refus), `handler()` ; `fetch_manifest(&Endpoint, impl Into<EndpointAddr>) -> Result<Manifest>` (borné, revalidé, `Error::Auth` si refusé). `MANIFEST_ALPN`, `MAX_MANIFEST_BYTES`. Protocole : 1 octet `M` -> JSON du manifeste. NB : l'enveloppe `unknown_mods` et le keepalive `K` de src-tauri n'existent pas ici (l'app doit les porter autrement).
4. `ResumableReceive::run` est `Send` : cause = `stream.map(closure).buffer_unordered` (HRTB), remplacé par `FuturesUnordered` + boucle (même concurrence). Test statique `run_future_is_send` (générique, Flaky, IrohTransport). `block_in_place` supprimable côté src-tauri.
5. `build_endpoint` : preset `Minimal` inchangé. `RelaySettings::address_lookup: bool` (défaut false ; true = publie clé+relais+IP chez n0 et leur interroge, documenté). `endpoint_addr_info(&EndpointAddr) -> EndpointAddrInfo{relay, addrs}` (bornes du code ami, non-loopback d'abord, `.into_payload(pk, epoch)`) et inverse `endpoint_addr_from_payload`.
Changements de signature : `RelaySettings` gagne un champ (littéraux `RelaySettings { .. }` à compléter par `address_lookup: false`, ex. iroh_backend.rs:395) ; les types privés `Control`/`GatedBlobs` deviennent publics sous de nouveaux noms. Le reste est rétrocompatible.
Tests : `cargo test -p cubelink-p2p` 107 OK ; `-- --ignored` 4 OK (dont `router_all` : un Router = ami (demande+accept) + présence + xfer + blobs + manifeste + tunnel, 2 endpoints loopback, intrus refusé sur manifeste et xfer ; 3 runs stables) ; clippy `-D warnings` propre. Aucune dépendance manquante.
